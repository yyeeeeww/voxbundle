VOX BUNDLE - 10 вокальных плагинов Audio Unit для macOS (Apple Silicon + Intel)

УСТАНОВКА
1. Дважды кликните "Install Vox Bundle.pkg" и пройдите установщик.
   Если macOS пишет, что не может проверить разработчика:
   Системные настройки > Конфиденциальность и безопасность > внизу "Всё равно открыть",
   затем снова запустите установщик.
2. Перезапустите FL Studio: Options > Manage plugins > Find plugins.
   Плагины появятся у производителя "Vox Bundle".

VoxComp   компрессор / де-эссер / лимитер
VoxEQ     эквалайзер
VoxHeat   сатурация
VoxSpace  ревёрб / дилей
VoxSynth  вокодер
VoxDouble даблер
VoxTune   автотюн
VoxPitch  питч-шифтер
VoxDevil  девил-компрессор
VoxAdlib  обработка эдлибов

DEVIL в каждом плагине включает перегруз.

Удаление: удалите Vox*.component из /Library/Audio/Plug-Ins/Components.
